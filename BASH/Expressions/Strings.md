ANSI-C escape sequences 

| escape char | meaning         |
| ----------- | --------------- |
| \a          | alert           |
| \b          | backspace       |
| \f          | form feed       |
| \n          | newline         |
| \r          | carriage return |
| \t          | tab             |
| \v          | vertical tab    |
| \\\         | backslash       |
| \\'         | single quote    |
| \\"         | double quote    |
| \\?         | question mark   |
| \nnn        | 3 octal digit   |
| \xHH        | hex             |
| \uHHHH      | unicode         |
| \UHHHHHHHH  | unicode         |
