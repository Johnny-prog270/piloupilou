
`$?`- return value of the last command

`$$`- PID of the current process

`$!`- PID of last background process

`$_`- argument of last command 

`$0`- name of the script

`$n`- nth argument

`$@`- list of all arguments

`#`-number of argument 

`$*`-list of all argument of one word

`$-`-options of shell

`~`-Home

`.`-current directory

`..`-sub directory
